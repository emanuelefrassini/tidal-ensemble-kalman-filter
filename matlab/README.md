# MATLAB coursework experiments

This directory preserves two MATLAB files from the original tidal-wave data assimilation coursework. They are **historical experimental files**, not a second validated implementation. The repository's tested, reproducible experiments are in Python under [`src/tidal_enkf/`](../src/tidal_enkf/).

## Files

- [`ensemblekfilter_2.m`](ensemblekfilter_2.m): An experimental Ensemble Kalman Filter with ensemble forecasts, sample forecast covariance, a Kalman gain, perturbed observation updates and a free-forecast section after the assimilation cutoff.
- [`wave1d_timestep_2.m`](wave1d_timestep_2.m): A separate one-step wave-model helper that perturbs the prescribed left-boundary water level. The saved `ensemblekfilter_2.m` directly computes its forecast steps and **does not call this helper**.

## Differences from the Python implementation

| Aspect | MATLAB experiment | Tested Python implementation |
|---|---|---|
| Observations in updates | Four stations including **Bath** | Vlissingen, Terneuzen and Hansweert; **Bath held out** |
| Boundary uncertainty | Shared autoregressive scalar in the EnKF script; the separate helper sketches boundary perturbations | AR(1) boundary error propagated as an augmented state **per ensemble member** |
| Validation | Exploratory code; no standalone MATLAB test suite supplied | Numerical tests, held-out station, twin experiments and free-forecast evaluation |
| Configuration | Hard-coded choices and dimensions | Explicit Python configuration and reproducible random seeds |

### Execution and numerical scope

The files depend on additional functions and course-specific settings (such as `wave1d_read_series`, `settings.A`, `settings.B`, `settings.h_left`, and `settings.ilocs`). They have **not been independently validated as runnable standalone scripts**, and contain experimental choices that may need correction for use outside the original environment.

The two MATLAB files are included as supplied; no numerical results in the main repository README were generated by them. Do **not** assume they will reproduce the Python experiments or their reported metrics. For a working implementation, follow the main [README](../README.md).
